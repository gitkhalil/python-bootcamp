# 100 Days of Python 🐍

My journey through Dr. Angela Yu's *100 Days of Code: The Complete Python Pro Bootcamp*.
Each `day-XXX/` folder contains one day's project — from beginner games to web apps and data science.

## Roadmap
- **Beginner (Days 1–14):** fundamentals, games (Hangman, Blackjack)
- **Intermediate (Days 15–31):** OOP, GUIs, error handling (Snake, Pong)
- **APIs & Web (Days 32–59):** requests, web scraping, first Flask apps
- **Web apps & databases (Days 60–81):** Flask, SQLAlchemy, REST APIs
- **Data Science & ML (Days 82–100):** Pandas, Matplotlib, Scikit-Learn

## Tech
`Python` · `Flask` · `Pandas` · `NumPy` · `Requests` · `BeautifulSoup` · `Selenium`
